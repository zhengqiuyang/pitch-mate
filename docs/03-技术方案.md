# 03 · 技术方案 【提案】

## 架构总览

```
浏览器/小程序
  ├── WebRTC / 小程序录音 ──→ 流式 ASR ──→ 对话编排层
  │                                          │
  │                              roleplay-core（Wave 0 抽离）
  │                              · 人设引擎（隐藏信息+剧本锚点）
  │                              · 多轮状态机（追问/打断/剧情推进）
  │                              · 评分流水线（rubric LLM + 规则引擎）
  │                              · SRS 队列
  │                                          │
  └── 流式 TTS（情感参数） ←─────────────────┘
                    │
             LLM 网关（OpenAI 兼容，多厂商可切换）
```

## 从 interview-mate 复用什么（Wave 0 的 roleplay-core 抽离范围）

| interview-mate 资产 | 复用度 | pitch-mate 需要的扩展 |
|---|---|---|
| 提示词工具协议（不绑厂商 function calling，任何 OpenAI 兼容模型可跑） | 100% | 无 |
| 多轮对话引擎（逐题追问、上下文管理） | 80% | 增加"隐藏信息解锁"状态机、剧本锚点调度 |
| 结构化评分（LLM rubric + 确定性规则混合） | 70% | rubric 换五维销售模型；新增逐句归因输出 |
| 间隔重复调度 | 90% | 复习对象从题目换成"薄弱场景×难度" |
| 三套 UI 主题/本地优先架构 | 50% | 企业版需多租户，架构改为服务端会话 |

**抽离纪律**：roleplay-core 作为独立 npm 包开发，pitch-mate 是第一个消费者；
interview-mate 不回填改造（避免动已上线产品），允许两版本短期分叉。

## 新增的核心工程量（也是简历亮点所在）

1. **语音实时链路**：流式 ASR（VAD 断句）→ LLM 首 token → 流式 TTS，端到端 ≤1.5s。
   方案：ASR/TTS 用云厂商流式 API；LLM 侧做"首句短回包"prompt 策略（先出语气词再出内容句，
   掩盖生成延迟）。这项延迟工程是 voice AI 岗位面试的硬通货。
2. **评分可信度**：rubric 评分的 LLM 一致性验证——同一对话重复评分 5 次，维度分方差 >阈值即
   降级为"区间分"。评测集（见下）持续回归。
3. **多租户与订阅**（团队版）：saas-starter 底座 + 席位管理、团队看板聚合查询。

## 评测集（eval-spec 规范的第一个落地）

- **golden-50**：50 段人工标注的陪练对话（含优秀/平庸/翻车三档），每段标注五维分与逐句问题点；
  构造方式：先用引擎自跑 + 人工改写出 20 段，试点团队真实练习贡献 30 段（脱敏）；
- 指标与门槛：评分与人工标注的维度相关性 ≥0.75；剧情锚点触达率 ≥90%（人设剧本必须走完）；
  语音链路 p50 端到端延迟 ≤1.5s、p95 ≤2.5s；
- 回归 CI：golden-50 每次改 prompt/换模型跑全量，报告进 GitHub Actions——
  直接套 agentbench-local 的任务集格式，让 infra 方法论在应用层复现。

## 技术栈（与仓库惯例对齐）

- TypeScript + ESM；服务端 Node ≥18 零重依赖（对齐 interview-mate 的"本地零依赖"传统，
  LLM/ASR/TSS 全部 API 化）；前端 Vite + 三主题体系移植；
- 部署：国内用户 → 云开发/轻量服务器；评测 CI → GitHub Actions 双平台；
- 数据：会话记录（脱敏后）是产品资产——沉淀为"中文销售对话语料"，长期可发 benchmark
  （对齐 interview-mate 的题库共建打法）。

## 成本模型（月度，1 个 50 人团队）

- LLM（对话+评分，人均 20 次/月 × 约 15k token）：约 ¥150-300；
- ASR+TTS（语音会话占 60%）：约 ¥200-400；
- 对 ¥199/人/月定价：毛利率 85%+，边际成本不是风险点，获客才是。
